# test1

A simple Electron application starter project.

## Getting Started

### Prerequisites
- Node.js 18 or newer
- npm or yarn

### Install dependencies
```bash
npm install
```

### Run in development
```bash
npm start
```

### Build for production
```bash
npm run build
```

## Project Structure
- `package.json` - project metadata and scripts
- `main.js` or `src/main.js` - Electron main process entry
- `renderer` or `src/renderer` - renderer process files
